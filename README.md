# Contact Book Using Python

## 📌 Description
This project is a command-line based Contact Book application developed in Python.  
It allows users to store and manage contact information such as name, phone number, and email.  

The data is stored locally using a JSON file, ensuring that contacts are saved even after the program exits.

This project was developed as part of CS50’s Introduction to Programming with Python final project.

---

## 🚀 Features
- Add a new contact  
- View all saved contacts  
- Search for a contact by name  
- Delete an existing contact  
- Data persistence using a local JSON file  

---

## 🛠️ Technologies Used
- Python 3  
- JSON (for storing contact data)  
- OS module (for file handling)  
- Pytest (for testing)
